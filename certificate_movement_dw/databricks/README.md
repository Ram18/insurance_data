# USS Certificate Movement — Databricks migration

Migration of the USS Certificate Movement model from SQL Server / Power BI to
**Databricks**, keeping the same Kimball star and reproducing the same business
numbers.

**Target layout (Unity Catalog):**

| Layer | Location | What |
| --- | --- | --- |
| Source | `adw_prod10.dbo.*` | The ADW tables, assumed already ingested/federated into UC |
| Gold star | `adw_prod10.star.*` | Conformed `Dim_*` + `Fact_Certificate_Movement` (Delta, Type 1) |
| Reporting | `adw_prod10.star.v_fact_movement_base` | Fact + dims joined, **5-period scope** applied here |
| Semantic model | `adw_prod10.star.certificate_movement_metrics` | **Metric view** — dimensions + all ~90 measures (replaces the Power BI dataset + DAX) |
| Dashboard | `dashboards/certificate_movement.lvdash.json` | **AI/BI (Lakeview)** movement summary |

**Mapping from the Power BI world:**

| Power BI / SQL Server | Databricks |
| --- | --- |
| Import dataset + relationships | Delta gold star in UC (`NOT ENFORCED` PK/FK for lineage) |
| DAX measures | `measures:` in the metric view YAML, queried with `MEASURE()` |
| Role-playing (`USERELATIONSHIP`) | Separate joins in the metric view (start/end aliases) |
| Report visuals | AI/BI dashboard widgets |
| Power Query 5-period filter | `v_fact_movement_base` reporting view |

**Build order (run in a Databricks SQL editor / notebook):**

1. `sql/00_create_schema.sql`
2. `sql/dimensions/01–07`
3. `sql/fact/08_Fact_Certificate_Movement.sql`
4. `sql/reporting/09_v_fact_movement_base.sql`
5. `metric_views/10_certificate_movement_metrics.sql`
6. Import `dashboards/certificate_movement.lvdash.json` as an AI/BI dashboard.

**Notes**

- Surrogate keys use `GENERATED BY DEFAULT AS IDENTITY` so the `-1` Unknown member
  can be inserted explicitly; generated values seed from 1 and never collide with `-1`.
- Constraints are declared `NOT ENFORCED` (Databricks does not enforce them) — they
  document grain/relationships and help BI tools and the optimizer.
- Loads are Type 1 `MERGE`, idempotent, safe to re-run. The fact is a full reload.
- Text is trimmed at load to match the source Power Query `Text.Trim`.
